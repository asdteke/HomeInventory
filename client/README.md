# HomeInventory Client

This React/Vite/TypeScript client documentation is current for the public v2.6.0 release line.

The client is maintained on the TypeScript/Vite component path. Feature history is tracked in [../CHANGELOG.md](../CHANGELOG.md); v2.6.0 adds shared/personal box workflows, single and bulk item assignment, mobile camera/gallery input, inline room-scoped location creation, and QR label printing through the existing inventory infrastructure.

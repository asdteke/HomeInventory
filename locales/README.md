# Locale Packs

These server-side locale packs are current for the public v2.6.0 release line.

The v2.6.0 line keeps 103 client UI packs and 103 server-side email/default-house packs aligned, including the box-management keys introduced in this release. English and Turkish remain manually reviewed; automated parity and localization-quality checks cover every locale, with per-key fallback retained as a safety net.
